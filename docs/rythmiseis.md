# Ρυθμίσεις

## Προφίλ

Εμφανιζόμενο όνομα του χώρου εργασίας.

## Γλώσσα

English / Ελληνικά. Σε νέα εγκατάσταση η προεπιλογή είναι τα
**Ελληνικά**· η επιλογή σας αποθηκεύεται.

## Εμφάνιση

Φωτεινό / Σκοτεινό / Σύστημα (ακολουθεί το κινητό).

## Αντίγραφο ασφαλείας

Βλέπε [Αντίγραφα ασφαλείας](backup.md).

## Συγχρονισμός Dropbox (κινητό)

App Key + Secret + refresh token, Αποθήκευση, Ανέβασμα/Λίστα/Κατέβασμα.
Λεπτομέρειες στο [Σύνδεση Dropbox](dropbox.md).

## Περίοδοι αρχικής

Λίστα περιόδων (μέχρι **6**) με κουμπί Επεξεργασία/Διαγραφή η καθεμία.
Φόρμα: όνομα + αρχικός/τελικός μήνας (1–12). Το κουμπί Προσθήκη
απενεργοποιείται όταν φτάσετε τις 6. Στο desktop η διαχείριση γίνεται
από **Ρυθμίσεις → Περίοδοι αρχικής** (Προσθήκη/Επεξεργασία/Διαγραφή).
