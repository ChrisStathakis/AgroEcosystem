# Πρώτα βήματα

## 1. Όνομα χώρου εργασίας

Στις **Ρυθμίσεις → Προφίλ** δώστε ένα όνομα (π.χ. «Το κτήμα μου»). Αυτό
φαίνεται στην αρχική οθόνη.

## 2. Φάρμες

Μενού **Φάρμες → Νέα φάρμα**: τίτλος (π.χ. «Ελαιώνας») και έκταση σε
στρέμματα. Χωρίς φάρμα δεν ξεκλειδώνουν δέντρα, εργασίες και συναλλαγές.

## 3. Κατηγορίες

Φτιάξτε από μία κατηγορία για να ξεκινήσετε:

- **Κατηγορίες εξόδων** (π.χ. Σπόροι, Λιπάσματα, Εργασία, Καύσιμα).
- **Κατηγορίες εσόδων** (π.χ. Πώληση σοδειάς).
- **Είδη δέντρων/καλλιεργειών** (π.χ. Ελιά, Πορτοκάλι).
- **Κατηγορίες εργασιών** (π.χ. Πότισμα, Κλάδεμα).

Η εφαρμογή έχει ήδη μερικές έτοιμες — προσθέτετε και σβήνετε ελεύθερα
(αρκεί να μη χρησιμοποιούνται από εγγραφές).

## 4. Επαφές (προαιρετικά)

**Προμηθευτές** (από ποιους αγοράζετε) και **Πελάτες** (ποιοι αγοράζουν
από εσάς). Μπαίνουν προαιρετικά σε έξοδα/έσοδα και μετά γεμίζουν
αυτόματα.
