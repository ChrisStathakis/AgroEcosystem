# Σύνδεση Dropbox

Το Dropbox χρησιμοποιείται για να **ανεβάζετε και να κατεβάζετε με το
χέρι** τα αντίγραφα ασφαλείας και έτσι να τα μεταφέρετε ανάμεσα σε
συσκευές (π.χ. υπολογιστής ↔ κινητό). Δεν γίνεται αυτόματος
συγχρονισμός — πατάτε εσείς **Ανέβασμα/Κατέβασμα** όποτε θέλετε.

!!! warning "Μυστικά κλειδιά"
    Το App Secret είναι σαν κωδικός — μην το μοιράζεστε και μην το
    ανεβάζετε δημόσια.

## Βήμα 1 — Φτιάξτε Dropbox app (μία φορά)

1. Ανοίξτε το [dropbox.com/developers](https://www.dropbox.com/developers)
   και συνδεθείτε.
2. **Create app** → *Scoped access* → *App folder* → δώστε όνομα
   (π.χ. `AgroEcosystem`).
3. Από τις ρυθμίσεις του app σημειώστε το **App Key** και το
   **App Secret**.
4. Προσθέστε το **redirect URL** που σας δείχνει η σελίδα Ρυθμίσεων της
   εφαρμογής (desktop), π.χ.
   `http://127.0.0.1:8517/profile/dropbox/callback/`.

## Βήμα 2 — Desktop

1. **Ρυθμίσεις → Dropbox**: επικολλήστε App Key + App Secret →
   Αποθήκευση.
2. Πατήστε **Σύνδεση Dropbox** και εγκρίνετε την πρόσβαση.
3. Πλέον φαίνεται «Συνδεδεμένο ως …».
4. **Αποθήκευση αντιγράφου στο Dropbox** — ανεβάζει το τρέχον backup
   στον φάκελο `/AgroEcosystem/`.
5. Για κατέβασμα: στη λίστα **Αντίγραφα Dropbox** πατήστε **Λήψη** στο
   αρχείο που θέλετε → ανοίγει η προεπισκόπηση επαναφοράς → διαλέγετε
   Αντικατάσταση/Συγχώνευση → Επιβεβαίωση.

## Βήμα 3 — Κινητό

1. **Ρυθμίσεις → Συγχρονισμός Dropbox**: βάλτε το ίδιο App Key +
   Secret.
2. Επικολλήστε το **refresh token** — θα το βρείτε στο desktop μετά τη
   σύνδεση (αποθηκεύεται στον χώρο εργασίας). Πατήστε Αποθήκευση.
3. **Ανέβασμα στο Dropbox** — ανεβάζει το τρέχον backup.
4. **Λίστα αρχείων Dropbox** → πατήστε ένα αρχείο (ή γράψτε τη διαδρομή
   του) → **Κατέβασμα από Dropbox** → μπαίνει σε εκκρεμότητα →
   διαλέγετε λειτουργία → **Επαναφορά**.

## Συχνά λάθη

| Πρόβλημα | Λύση |
|---|---|
| «Βάλτε πρώτα App Key + Secret» | Συμπληρώστε και τα δύο πεδία και αποθηκεύστε. |
| Η σύνδεση ακυρώθηκε / redirect error | Ελέγξτε ότι το redirect URL στο Dropbox app είναι ακριβώς ίδιο με αυτό των Ρυθμίσεων. |
| «Could not refresh Dropbox access» | Το token έληξε ή άλλαξε το Secret → **Αποσύνδεση** και σύνδεση από την αρχή. |
| «Too large (5 MB)» | Το αρχείο ξεπερνά το όριο — σβήστε παλιές/άχρηστες εγγραφές και ξαναδοκιμάστε. |
| Κατέβασα αλλά δεν βλέπω αλλαγές | Ελέγξτε ότι πατήσατε **Επαναφορά** μετά το κατέβασμα (το κατέβασμα από μόνο του δεν αλλάζει δεδομένα). |
| Replace vs merge | **Replace** σβήνει πρώτα τα πάντα· **Merge** κρατάει τα υπάρχοντα. Πριν το replace, πάντα backup! |
