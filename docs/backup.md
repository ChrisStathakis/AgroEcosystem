# Αντίγραφα ασφαλείας

Τα δεδομένα σας αποθηκεύονται σε ένα αρχείο JSON (ίδια μορφή σε desktop
και κινητό). Όριο μεγέθους: 5MB.

## Αποθήκευση (backup)

- **Desktop:** Ρυθμίσεις → Τα δεδομένα σας → Λήψη αντιγράφου (JSON).
- **Κινητό:** Ρυθμίσεις → Αντίγραφο ασφαλείας → Λήψη αντιγράφου.

!!! warning "Κανόνας"
    Κρατάτε αντίγραφο **πριν** από κάθε επαναφορά ή διαγραφή.

## Επαναφορά (restore)

1. Διαλέγετε αρχείο αντιγράφου (ή προεπισκόπηση τρεχόντων δεδομένων).
2. Βλέπετε την **προεπισκόπηση** (πόσες εγγραφές έχει κάθε ενότητα).
3. Διαλέγετε λειτουργία και πατάτε Επαναφορά:
    - **Αντικατάσταση** — σβήνει πρώτα όλο τον χώρο εργασίας και
      φέρνει το αντίγραφο (προσοχή!).
    - **Συγχώνευση** — κρατάει τα υπάρχοντα και προσθέτει όσα λείπουν
      (όσα υπάρχουν ήδη παραλείπονται).

## Διαγραφή χώρου

Η επικίνδυνη ζώνη σβήνει **όλα** τα δεδομένα του χώρου (ο λογαριασμός
μένει). Θέλει πληκτρολόγηση επιβεβαίωσης και δεν αναιρείται — πρώτα
backup!
